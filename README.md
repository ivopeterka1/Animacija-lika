# 🧑‍🎨 2D Character Animation Project

This project is a simple **2D animation demo** built in **C# with Visual Studio**, where I explored the **fundamentals of character animation**.  

The character can move freely across the field in four directions: **up, down, left, and right**.  
For each direction, a unique **4-frame walking animation** was created, giving the movement a more natural and retro look.  

Through this project, I learned the basics of:
- Creating and managing sprite sheets 🖼️
- Handling directional movement 🎮
- Applying frame-based animations in 2D 🕹️

## ⚙️ Features
- Smooth 2D character movement.
- 4-frame walking animations for each direction.
- Built from scratch in **C#** with Visual Studio.

## 🚀 How to Run
1. Open the solution file in **Visual Studio**.
2. Build and run the project.
3. Use arrow keys (↑ ↓ ← →) to move the character.
